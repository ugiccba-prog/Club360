Instructivo para ugiccba-prog/ugiccba-site

Cómo dejarla en www.ugiccba.com.ar/hockey con Guardado en Vivo

1. ¿Por qué necesitamos conectar un Google Sheets?

Tu web www.ugiccba.com.ar está alojada en GitHub Pages. GitHub Pages sirve páginas rapidísimo pero no tiene base de datos propia. Al vincularle una hoja de cálculo de tu Google Drive con el código de abajo, Google Drive pasa a ser el motor en tiempo real: cuando el Entrenador 1 cambia un puntaje en la Estación 1, se guarda en tu Drive y a los pocos segundos aparece en la pantalla del Entrenador 2 y del Comité.

Paso 1: Preparar la Planilla en tu Google Drive (1 minuto)

  1. Abrí una planilla nueva en tu Google Drive (ej: "Base Datos Selectividad Hockey 2027").
  2. En el menú superior de Google Sheets, entrá en Extensiones → Apps Script.
  3. Borrá lo que haya y pegá este código completo:
function doGet(e) {
  var prop = PropertiesService.getScriptProperties().getProperty('CCBA_PLAYERS_2027');
  return ContentService.createTextOutput(prop || "[]").setMimeType(ContentService.MimeType.JSON);
}

function doPost(e) {
  var body = e.postData.contents;
  PropertiesService.getScriptProperties().setProperty('CCBA_PLAYERS_2027', body);
  return ContentService.createTextOutput(JSON.stringify({ok: true})).setMimeType(ContentService.MimeType.JSON);
}
  1. Arriba a la derecha en Apps Script, tocá el botón azul Implementar → Nueva implementación.
  2. En "Seleccionar tipo" elegí Aplicación web.
  3. En "Ejecutar como" dejá Yo, y en "Quién tiene acceso" elegí Cualquier persona (fundamental para que los entrenadores no tengan que loguearse).
  4. Copiá la URL de la aplicación web que te entrega (`https://script.google.com/macros/s/.../exec`).

Paso 2: Subirlo a tu repo ugiccba-prog/ugiccba-site

  1. En este archivo HTML, buscá la constante FIXED_GOOGLE_SCRIPT_URL = "" (al principio del script) y pegá ahí tu URL de Apps Script para que ya quede grabada de fábrica para todos los entrenadores.
  2. En tu repositorio de GitHub ugiccba-site, creá una carpeta llamada hockey y subí este archivo adentro con el nombre index.html (así entran directo con www.ugiccba.com.ar/hockey).
